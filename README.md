# Product Sourcing & Availability Catalog (供应商产品采购核实单)

Official interactive catalog for Chinese supplier product sourcing, quotation, lead time verification, and factory stock availability.

## Structure
- `index.html` / `mimmolo_supplier_catalog.html`: Interactive web catalog with 184 products, high-resolution photos, variants, detailed specifications, and fillable quotation panels.
- `mimmolo_supplier_sourcing_sheet.xlsx`: Formatted quotation spreadsheet with bilingual headers for WeChat/email submission.
